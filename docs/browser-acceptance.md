# 浏览器验收流程

使用Codex CUA浏览器接口操作本地 `healthy-care-test`（8782），不在命令行启动Playwright。测试输入和图片均为合成内容；真实医疗能力与平台账号调用另行验收。

执行前先运行一键软件验收，避免中途重置测试数据。浏览器测试步骤：

1. 新建合成个人账户，检查首页无预置病程、统一今日关照和图文输入。
2. 发送不适描述，确认前检查待确认卡；确认后检查当前不适首页。
3. 发送实际自评分与“明确未用”，确认并检查病程时间线。
4. 通过filechooser添加合成PNG，检查预览、纯图片发送、私有图片显示和放大弹窗。
5. 通过对话归档，检查恢复询问新需求，旧事件标记为非当前不适，保留历史观察。
6. 检查390×844手机视口、根文档横向溢出，保存截图后恢复默认视口。
7. 检查健康记录与影像分别默认未授权，直接进入科研路径时普通账户被拒绝。
8. 用独立科研账户登录；切换皮肤主题、3天窗口，检查87.5%和21/24患者日。
9. 打开记录详情，检查来源编号、合成自述、缺失评分与实际用药。
10. 保存队列，启动本地参考计算，刷新任务查看真实完成状态、数值和输入/方法版本。
11. 检查未配置SciencePal时按钮禁用；文献库包含4篇研究和6条护理参考，原文链接可见。
12. 检查科研手机布局、文献与用户可见文案；保存桌面截图，检查浏览器运行错误。

另行回归未知起病时间与删除确认前的备份保留说明。

本轮实际执行结果与截图见 `acceptance-report.md` 和 `screenshots/`。上传chooser必须先等待filechooser事件，再交付本机绝对路径；截图使用浏览器tab.screenshot，避免原生窗口截图与临时视口比例不一致。
