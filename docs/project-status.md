## 证据与限制

2026年10月23日保留了32项运行时、6项真实模型基础、19项完整业务检查的通过记录；10月30日验证了专用评审身份与角色边界，并在科研评审账号下完成SciencePal任务。

固定合成患者日任务与追问组件对照是独立任务。前者显示267/324患者日有记录，完整率82.4%，32项用药待核对候选；后者使用48例合成留出事件、16模板簇，定向减通用为+2.01个百分点，95%区间[-4.31,+10.69]包含零。

全部实验和演示案例为合成数据；尚无独立真人可用性结果、疾病识别准确率或临床收益证据。具体药品用量尚未发布，在线医生、处方确认与购药尚未接入。
