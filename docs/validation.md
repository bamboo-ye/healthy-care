# 前端原型验证

验证日期为2026年10月18日。以下验证针对本地交互原型，不代表医学判断、模型能力或真实后端验证。测试输入和截图中的病程均为人工编写的界面测试内容。

## 用户端

- 用户端与科研端使用不同HTML入口和业务脚本；用户端没有科研导航或角色切换，不展示伴AI的其他业务模块。
- 首次首页为每日健康，显示日常关照、环境背景入口和图文输入，没有预置症状、用药、评分或病程。
- 用对话补充“我平时皮肤容易干燥”“我在上海”后，个人关照使用这些背景，但仍显示没有正在进行的不适；没有生成当地温度或预警。
- 描述“这两天喉咙有点不舒服，今天大概3分，没有胸痛”后，建立用户自述记录，提取持续描述和3分评分。否定的胸痛没有触发求助提示。此检查不证明能正确理解所有否定或危险信号。
- 每日健康展示当前自述、持续情况、实际评分、资料来源和观察重点，没有复述整段聊天或补造过去的评分。
- 同一天补充2分及实际用药后，仍只有一个观察日期，记录版本更新为第3版；自述用药标为待核对。
- “每天晚上8点半提醒我记录”可记录为20:30的站内计划；页面明确没有系统推送。
- 使用两张项目内生成图片验证了多图选择，移除一张后文字草稿保留；图文一起发送后图片可放大并关闭弹窗。图片只在本页使用对象URL预览。
- 表示恢复并结束记录后，首页显示“暂无进行中的不适”、康复后的建议、明确标注已结束的历史小结、实际历史数据观察及个人环境关照。点击回顾仍不重新激活病程。
- 桌面1440px与手机390px视口已检查；手机文档宽度与内容宽度相同，没有页面级横向溢出。手机标题与对话入口没有异常折行。

## 科研端

- 已升级为八个科研视图和四类分析：连续记录字段覆盖、用药情境候选、缺失敏感性、历史线索时序边界。所有结果来自固定合成数据，未运行医学模型。
- 默认60份合成事件中48份授权可用。用户端研究选择只增减固定合成样例S001；浏览器验证48→49→48，未传输用户文字或照片。
- 5项共同字段以参与者×字段槽位为分母；纵向新增的变化描述单列，不增加对照改善率。默认首次140/240、窗口内235/240；差39.6个百分点是合成过程指标。
- 已结束事件不继续增加应记录日，默认应记录324日、已记录267日。导出CSV实查324行、48个合成参与者：137日明确使用、103日明确未用、27日记不清、57日缺失，与页面一致。
- 用药候选可定位并高亮对应日期的用药自述，来源ID独立于症状描述；成分证据可直接核对。规则检查不把未知或跨日相同成分误计为同日重复。
- 边界样例验证了组合信息齐全、明确否定、缺失和未来信息隔离。切换到7天窗口后，窗口外记录不进入当前判断。这不是疾病筛查性能验证。
- 浏览器本地分析实际计算并生成输入SHA-256；与Python参考计算在默认、3天及皮肤主题三个队列中全部指标一致。
- Python报告在浏览器中成功导入；另一个窗口的报告、篡改哈希和篡改统计值分别被拒绝。修改队列筛选后旧报告失效。
- 小于5人的队列隐藏聚合并禁止导出。真实身份认证与导出审计未实现，演示抑制策略不代表匿名保证。
- 桌面1440px完成交互与视觉检查。手机通过390px固定宽度嵌入预览检查导航、问题切换、分析卡片、数值和表格；这是响应式检查，不是真实设备测试。
- SciencePal实际执行尚未发生。页面区分local-browser、local-python与文件声明的来源；导入一致性检查不认证执行地点。

复核命令：`node analysis/test_research.js`。固定输入与Python输出位于 `analysis/demo-input.json` 和 `analysis/demo-output/`。方法、资料来源与边界详见 `research-design.md`。

## 文件与边界

所有JS脚本通过Node语法检查，HTML引用的本地素材与脚本存在。绿色角色PNG为1254×1254并保留透明通道，背景为1672×941，两者均已接入用户端。

本地规则仅演示部分自然语言流程，复杂更正、并行病程、医学分流、药品适用性、早期症状知识匹配和真实图像理解均未接入模型与后端。天气服务、真实通知、在线问诊、购药和医生确认未实现。个人记录仅本页有效，刷新清空。

## 用户端布局调整复核

- 桌面1440px下，问候与输入并排；当前分析和趋势、建议和观察分别对齐。日常、康复与个人环境内容合并为唯一的今日关照模块，历史观察与小结在其下方排列。
- 病程在桌面使用趋势与时间线双栏，手机为单列；用药、历史线索、个人授权的标题和操作区使用统一样式。
- 900px平板、390px手机与320px窄手机均检查过，页面内容宽度等于视口内容宽度，没有水平溢出。角色与问候、按钮与标签没有重叠。
- 个人授权入口有明确选中状态；图文输入仍可发送。图片缩略图预留固定空间，减少加载引起的对话位置变化，点击可放大。
- 合并关照后，桌面与手机均只有一个“今日关照”模块；个人背景、城市和恢复记录参与同一建议列表，旧的独立环境关照卡数量为0，手机无横向溢出。
- 布局改动由用户端独立CSS加载，科研端入口未引用该文件。
