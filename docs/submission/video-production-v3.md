# 视频第三版制作记录

目标：真实操作已部署产品，采用虚构日常新冠案例；无图片上传、无配音、无音轨。片长计划4分45秒，科研问题与工作流程约占65%。

## 画面与字幕

开场以院外健康记录的采集与分析问题展开。个人端呈现对话、病程、实际用药、提醒、恢复后的首页及独立研究选择。科研端保留约80秒的同一录屏连续片段，依次呈现数据概览、窗口切换、记录状态、待核对候选与来源。后续查看已经完成的SciencePal任务，再回到字段覆盖、逐日记录和评分变化。

产品界面和模型回应来自真实运行，不在剪辑中改写界面。字幕仅说明功能使用流程。影片保留简短的“虚构案例演示”角标，不把这些记录标为真实患者或临床效果证据。

## 数据与范围

用户于本轮明确允许最多7个虚构演示账户，向其中6个授予结构化记录研究用途。6个科研案例通过产品实际API录入，用户端另建1个无研究授权的账户。没有上传图片，没有使用真实患者资料。私有凭据与原始运行信息仅存在.local中，不进入交付。

为防止科研录屏混入其他账户，先仅查询日期范围内聚合计数；结果为本次6个虚构账户、其他账户0条。日期过滤限定2026-10-25，随后读取这6个案例的科研视图。

SciencePal章节单独展示已有完成任务，其分析的是界面标明的固定合成队列。新建的虚构账户记录属于已授权来源，当前产品未开放该来源的SciencePal外部执行，因此不将这两个队列混称为同一次分析。

## 交付

输出为output/video-v3/healthy-care-demo-v3.mp4及对应SRT，保留原始标签页录屏、编辑映射与媒体检查证据。第二版视频保持原样。

2026-10-29完成：285.000秒，1920×1080，30fps，H.264，0条音频流；完整解码通过。科研主段80秒由同一新录制来源的相邻区间连接，压缩等待但不跳过流程。全片使用本轮新录制素材，未复用含测试措辞与图片的第二版个人端录屏。字幕已按操作内容核对。
