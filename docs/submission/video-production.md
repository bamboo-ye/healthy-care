# 演示视频制作与核验

成片：output/video/healthy-care-demo.mp4，1920×1080、H.264视频及AAC中文旁白，约237.6秒（3分58秒）。每页标注“实际界面分步讲解·合成场景·非连续录屏·AI配音”。

本片由实际界面截图与讲解组成，不宣称是连续屏幕录制；包含2026年10月19日至24日的不同实际操作阶段。素材来自docs/screenshots/与output/video/captures/；后者有实际归档确认、归档后首页和独立研究授权界面。组件结果页来自已核验五页说明的对应结果表，患者日平台截图不冒充组件实验任务。

旁白由macOS Tingting语音合成，脚本scripts/build_demo_video.py保留所有文本和镜头来源。生成器依赖macOS say、ffmpeg/ffprobe及Arial Unicode字体；其他平台可替换语音生成器。过程素材和时间轴位于output/video/。3至5分钟时长、视频/音频编码、非静音音轨与实际关键帧均已检查；不是临床效果证据。

视频内容可提交，但最终署名、公开访问和团队对内容的确认仍需完成。若主办方要求连续操作录像，需要另录，不能用本片冒充。
