# 新版演示视频制作脚本

2026-10-29。主题：从新冠自述场景的日常关照，走向可追溯的院外健康研究。参考成熟产品宣传片的表达形式，不复刻第三方素材。

## 制作约定

- 目标4分45秒，1920×1080、30fps、中文旁白及字幕。
- 科研叙事约62%，个人功能约34%，品牌收尾约4%；动态动画约25%，真实页面连续录制约75%。
- 使用专用虚构账户、合成图片；新冠抗原阳性为用户自述，不是图像判读或模型确诊。
- 用户端录制病程建立、随访确认、实际用药、图片补充、明确时间的站内提醒、归档及康复关照。
- 科研端继续使用已有48例混合小病合成队列，不更名为新冠队列，不暗示用户账户产生了该队列。
- SciencePal由科研端API调用，成功后自动取回及校验产物；网页仅作执行核验镜头。
- 录屏来源为浏览器getDisplayMedia选定的本次演示标签页，MediaRecorder连续采集。源文件保留；成片分章节剪辑，等待与操作加速有标识，跨场景和时间关系明确提示。
- 不展示具体产品剂量、自动抗原判读、大病预测、外部推送、购买药品、医生服务或实时天气。

## 验证口径

48例混合小病合成队列、7天窗口：267/324人日，82.4%；用药候选32条，不能解释为滥用率或真实人群频率。

独立采集组件实验：48个合成留出案例、16个模板簇；初始/通用/定向方案的来源支持字段宏平均召回率30.10%/77.95%/79.97%；失败0/2/1例保留计入。定向相对通用+2.01个百分点，95%模板簇bootstrap区间[-4.31,+10.69]个百分点，包含0，尚不能证明定向更优。该组件不等于临床或产品整体准确率。SciencePal执行已有模型观测的评分和复核，不声称模型采集发生于SciencePal。

## 录制输入

1. “这是合成演示：我28岁，今天自己测的新冠抗原是阳性，昨天开始喉咙疼、鼻塞，目前没有呼吸困难。想了解需要留意什么，也请帮我记录这次不适。”
2. “记录今天的变化：咽痛3分，鼻塞还在，今天没有用药。”
3. “补充实际用药：昨天吃过对乙酰氨基酚，但规格、次数和具体时间记不清了，请按未知保留，不要帮我补全。”
4. 上传有显著合成标记的检测示意图，仅展示补充沟通与预览，不判阳阴。
5. “提醒日期明确为2026年10月30日晚上8点，时区Asia/Shanghai，只提醒一次，内容是记录症状变化。”
6. 独立情景：“这是恢复后的合成情景演示：这次不适已经恢复，我想结束跟进并归档。”不冒充已真实过了数日。

模型回复与保存结果必须来自真实服务；不把脚本中的预期反馈贴入界面。提醒相对日期首次生成偏差未确认，改用绝对日期，保留原始录制。
