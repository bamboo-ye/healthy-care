# 伴AI·健康伙伴：院外轻症连续记录与可核实研究数据

五页项目说明，2026年10月26日更新。每个“第X页”为一个页面。证据包含本地软件验收、真实图文模型合成输入调用及SciencePal实际执行；不包含真实患者研究或临床效能验证。个人参赛；演示视频及公网服务已完成，署名信息待本人确认。

## 第1页 · 问题与使用场景

日常小病常在院外自行处理，症状变化、实际用药和未就医经历难形成连续、可追溯的记录。自由对话可能遗漏开始时间、变化、活动影响和实际使用；没有记录也不能直接理解为没有用药。

伴AI·健康伙伴面向适合自主处理的成年人：用文字和图片描述不适，核对AI整理的草案，记录每日变化、实际用药和提醒，结束后保留历史观察与关照。入口不要求选择病种，也不限于湿疹；范围外情况仍能保留原话并提示进一步求助。

独立科研端面向获得用途授权的结构化记录。核心科学问题是：来源约束与定向追问能否改善院外轻症、自主用药记录的完整性和可核实性？已补充冻结合成事件的真实模型组件对照；当前证据尚不能回答真实人群的临床获益。

## 第2页 · 核心流程与实现

图文描述 → 信息补充与来源核对 → 用户确认 → 实际记录与连续随访 → 每日健康与归档 → 独立研究授权 → 冻结研究输入 → 分析与受控导出。

Go负责身份、确认事务、版本、附件及授权；Python LangGraph负责对话图、检查点、确认中断和恢复；PostgreSQL/pgvector保存事实与版本，Redis用于公共知识缓存和限流；Docker Compose提供单机复现、备份和恢复。

消息先保存，再派发运行；重复发送复用幂等键。失败或取消保留原图文，可发起新运行重试。模型提出动作草案，用户确认后由Go校验并写入。资源版本取自运行时读取快照，确认时检查当前版本。格式失败最多重试一次，原始输出通过校验后才展示。未知、明确未用与没有记录分开处理。

本轮按用户确认的范围提供护理参考、实际用药记录与信息核对，不发布具体产品用量说明。已实现的版本化产品说明接入能力，须取得真实专业审阅依据后才能发布相应内容；日常使用不要求平台医生确认。

## 第3页 · SciencePal与科研工作区

科研端包括概览、字段覆盖、用药待核对、记录缺失、评分描述、历史组合、队列、任务与文献。日期、主题、3/7天窗口、产品和可用性影响同一份输入；提供纳入与排除原因。真实研究默认不开放聊天、备注、身份或图片，授权撤回使旧快照失效。

SciencePal承担核心科研工作流创作与实际执行。已实现Agent API适配：上传冻结合成JSON、manifest和Python脚本，启动、查询、补充、停止、获取沙箱产物，核对输入哈希、方法版本和分子分母。导入数值一致不单独认证平台执行。

已在SciencePal网页创作“伴AI·健康伙伴｜院外健康科研Agent”v0.1.0；实际任务已完成，平台Python执行退出码0，报告、3份CSV与stdout/stderr由认证API取回，Go独立数值校验通过，结果记为api-fetched-artifact。上传资料均为合成输入，不含真实聊天、影像或密钥。

[查看SciencePal公开科研运行](https://sciencepal.ai/share/65ecd584-6adf-4000-88d9-4004e3f82a65)。该组件实验已实际执行评分，认证API产物与独立重算一致；公开只读链接已用未登录浏览器验证。截图为另一项已完成的患者日分析任务。

## 第4页 · 已取得的验证证据

新增实验先冻结60个合成事件，按模板簇划分开发12例、保留测试48例，覆盖呼吸道、皮肤和胃肠场景。使用同一真实模型，比较初始描述、通用结构化追问及定向结构化追问；两种追问各限一轮、最多3个字段。隐藏事实仅由固定响应器按实际问题披露，不交给提问模型。

| 条件 | 测试事件 | 来源支持的字段召回率 | 失败 |
| --- | --- | --- | --- |
| 初始描述 | 48 | 30.10% | 0 |
| 通用追问 | 48 | 77.95% | 2 |
| 定向追问 | 48 | 79.97% | 1 |

主要指标按事件平均，失败记0。定向减通用为+2.01个百分点；16模板簇、2000次配对bootstrap的95%区间为[-4.31,+10.69]个百分点。区间包含零，尚未证明定向策略更优；3次连接中断与失败记录完整保留。

这是结构化字段追问组件试验，初始输入带字段标签、使用固定响应器；不是自然聊天、生产整体或临床研究。未知自述与null编码仍有歧义，下一版需先用开发集固定定义，再另建独立测试集，不能回改本轮结果宣称优势。

既有端到端19项流程、图片色块传输、软件回归及SciencePal患者日计算通过。患者日267/324（82.4%）仅为合成统计复现；用药候选不等于滥用率。方法、原始合成响应、脚本与独立复算材料随实验包提供。
