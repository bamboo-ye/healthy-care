SciencePal承担核心科研分析与方法验证。项目在平台创作并运行“伴AI·健康伙伴｜院外健康科研Agent”，处理冻结的数据包，检查输入与方法版本，实际执行Python脚本，生成数据质量、患者日覆盖和用药待核对结果。另一项独立实验由SciencePal对已经采集的模型观测进行三臂评分和置信区间计算。用户端日常对话由业务侧模型提供，科研任务通过API与SciencePal联动，产物回传后再进行独立数值校验。

启动步骤：①使用专用科研评审账号进入科研端；②将“数据来源”设为“合成数据演示”，选择症状主题与3天或7天观察窗口；③进入“分析任务”，点击“启动SciencePal任务”。系统自动冻结当前输入，上传JSON、manifest清单及版本化脚本，启动平台Agent；④在任务列表查看状态，完成后打开详情，查看指标、执行日志、输入哈希和方法版本，也可下载冻结输入与执行任务包。已有完成任务可直接查看。通过科研端操作无需切换到SciencePal，也无需评审自行配置API Key。当前外部执行仅开放合成数据，不上传真实患者聊天、身份或图片。

示例输入：使用内置的固定48人合成院外记录，选择7天窗口，随任务提供health-research-input.json、manifest.json和run_analysis.py。示例指令：“请核对附件输入与版本，实际执行脚本，统计记录完整率，分别报告已用、明确未用、未知及无记录，输出用药待核对候选及运行日志；不要补造缺失值。”

预期输出：report.json、quality.csv、patient_days.csv、medication_candidates.csv，以及stdout/stderr日志和运行记录。既有固定快照的完成结果为267/324个患者日有记录，完整率82.4%，产生32条用药待核对候选；这些是合成演示统计，候选不等于证实滥用。更换队列或窗口后结果随输入变化。

访问方式：科研端需要专用科研角色账号，凭据通过主办方指定的非公开渠道单独交付，普通注册账号没有科研权限。SciencePal公开只读回放无需登录，可查看执行过程及结果：https://sciencepal.ai/share/65ecd584-6adf-4000-88d9-4004e3f82a65 。该回放展示独立的追问组件评分实验，与上述患者日分析为两项任务。若希望在评审自己的SciencePal账户复现，可下载执行任务包，登录具备代码执行与文件读写能力的Agent，上传输入、清单和脚本后运行；只读回放本身不能编辑或重跑任务。
