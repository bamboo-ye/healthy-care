# 第七版：安全性与在线医生规划

本版按确认的安全性分镜制作，加入38秒动画与同音色旁白。沿用1.15倍MiniMax Speech 2.8 HD沉稳男声、104 BPM轻快原创配乐，保留片头及片尾音乐提示。

## 新内容

- 1:30–2:08：AI健康决策风险、持续连接、连续记录、拟接入在线医生、研究授权与院外用药研究。
- 1:52–2:00：在线医生处方确认规划。画面持续标注“拟接入 · 概念演示”，展示用户选择转交摘要、在线医生评估及处方确认的可选服务分支。没有真实连接问诊或开具处方。
- 2:28–3:48：原有80秒科研端连续操作，画面素材完整复用。

研究授权与转交记录给医生分别呈现。安全性效果表述为“为识别和减少风险积累证据”，没有宣称项目已经证明能降低临床风险。

## 剪辑与音频

整体仍为4:59。用户端、恢复关照、研究授权、SciencePal任务、数据复核及片尾的素材区间均保留，通过调整各段播放时长为新内容腾出空间。旁白没有额外加速。

原有39处旁白复用原始片段；六处新旁白以相同设置在MiniMax生成，使用355点，生成后余额6977点。原始新增WAV包含明确的分段停顿，后期移除这些停顿后对齐动画。新版共45条字幕。

音乐按新时间线重新编排，风险说明部分降低打击乐活动，旁白时持续避让。片尾主题在4:48呼应，最后一句旁白结束后在4:57.55进入结束旋律。
