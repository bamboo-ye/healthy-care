# 独立可用性反馈执行单

状态：准备完成，尚未招募或执行，不把模拟反馈冒充真人结果。

邀请5–8位知情成年人，仅扮演以下虚构记录任务，不提供自己的健康资料，不实际服药。自愿参加、可随时停止。记录匿名编号，不收集真实健康信息；如录屏需另行取得明确同意。

1. 新用户描述鼻塞，补充持续时间、活动影响和实际未用药；确认前检查系统是否已经写入。
2. 记录虚构用药，再更正名称，检查是否出现两条重复记录。
3. 同日更新自评分，检查日期计数与更正后值。
4. 结束跟进，确认首页旧记录不再被当作当前不适。
5. 找到研究授权的用途范围，再撤回授权。

每任务记录开始/结束时间、是否完成、错误步骤、修改次数、求助次数。任务后询问：“哪些内容已经保存，哪些还没确认？”“哪里难以理解？”“你是否认为系统给出了确诊？”不要暗示预期答案。

汇总只写实际完成数/人数、中位完成时间、常见困难和原话节选（经允许）；不用满意度代替医学有效性。没有参加者数据时保持未执行。
